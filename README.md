# Markd — Official Releases (`markd.aramudan.dev`)

Pre-compiled native C++20 / Qt 6 release binaries and checksums for **[Markd](https://markd.aramudan.dev)** — the native Markdown instrument for the command line.

## Install on macOS (Apple Silicon)

### Homebrew Tap (Recommended)
```sh
brew install nodesman/markd/markd
```

### Direct POSIX Installer (`~/.local/bin/markd`)
```sh
curl -fsSL https://markd.aramudan.dev/install.sh | sh
```

### Standalone Application Bundle (`.dmg`)
Download **[Markd-0.1.0-macOS.dmg](https://markd.aramudan.dev/releases/v0.1.0/Markd-0.1.0-macOS.dmg)** and drag `Markd.app` to `/Applications`.
